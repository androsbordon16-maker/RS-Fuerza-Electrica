# Business Web Design

Build mobile-first, professional service pages with a clear business objective.

## Workflow

1. Identify the primary visitor, desired action, services, proof, and contact method.
2. Define a page outline before coding: hero, value proposition, services, process, trust signals, contact CTA, footer.
3. Implement with semantic HTML and accessible controls. Use real headings in order; label every form input; keep interactive targets comfortably tappable.
4. Optimize for phone width first, then tablet and desktop. Never hide essential content only because the screen is small.
5. Use focused visual hierarchy: one primary CTA, readable contrast, consistent spacing, and no decorative UI that weakens the technical-professional tone.
6. Include meaningful loading, empty, success, and error states whenever the interface uses forms or data.
7. Verify keyboard navigation, visible focus, image alt text, and reduced-motion behavior before delivery.

## Acceptance Checklist

- Explain what the business does in the first screen.
- Give the visitor a clear next action: WhatsApp, quotation, call, or contact form.
- Avoid generic claims; use specific services, areas served, certifications, experience, or project evidence when available.
- Keep the page fast: reserve image dimensions and avoid unnecessary animations or large media.
- Test at approximately 375 px, 768 px, and 1440 px wide.
